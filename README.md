# Impara! — app d'apprentissage de l'italien

PWA (page statique) servie par GitHub Pages. Les notifications et l'API tournent sur Supabase (projet `impara-italiano`).

- `index.html` — l'application (vocabulaire, répétition espacée, grammaire, jeux, onglet Oggi)
- `sw.js` — service worker : réception des notifications push, ouverture de l'app
- `manifest.webmanifest`, `icon-*.png` — installation sur l'écran d'accueil
